# Parsor

Convertit un intitulé de poste (ex. « directeur marketing ») en recherche booléenne complète pour LinkedIn Sales Navigator : synonymes FR/EN, acronymes (CMO, DAF, DRH…) et exclusions (assistants, stagiaires).

Page statique, sans dépendance ni serveur : tout tourne dans le navigateur (`index.html`).

En ligne : https://adimby.github.io/parsor/
